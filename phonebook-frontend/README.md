# Phonebook Frontend - Modern UI

Vue 3 + Vite + Axios frontend for the Phonebook backend.

## Includes
- Add contact
- View contact
- Edit contact
- Delete contact
- Search by name or phone number
- Server-side pagination
- Page size selector
- Modern responsive dashboard UI

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173

Backend must be running at http://localhost:8080.
